How it works
  1. Find the pancake: keep the golden-brown pixels and fit a circle to them.
  2. Find the syrup: inside that circle, mark anything whose color is far from the pancake's usual color. This works for chocolate, strawberry sauce or any flat topping. Then clean up specks.
  3. Distance map: for every pixel, measure how far it is from the nearest syrup.
  4. Place spots: Hug walks rings at a set distance around the syrup. Take turns alternates toppings on one ring. Sprinkle scatters them, nearest the syrup first. Spots never overlap the syrup, each other, or the pancake edge.
  5. Show everything at once: real-size circles in millimetres, using the pancake diameter.
